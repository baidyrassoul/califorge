# Validation Survey — CaliForge

> ⚠️ **Important:** this is questionnaire **type 1 of 3**. See the "Questionnaire
> strategy" section at the end of this file so we never confuse them.

Post this survey on Reddit (r/calisthenics, r/bodyweightfitness, r/streetworkout),
Discord servers and Facebook groups. Target: **50+ responses minimum** before
deciding to build.

Rules:
- Keep it under 3 minutes.
- Do NOT mention "we are building X, will you use it" — ask about their real
  behaviour first, THEN the product idea at the end. This reduces bias.

## Questionnaire strategy (the 3 types)

| Type | When | Who | Tool | Status |
|---|---|---|---|---|
| **1. Validation** | Phase 0 (now) | General calisthenics practitioners (Reddit/Discord/groups) | Tally.so or Google Forms | 🟡 this file is type 1, ready to publish |
| **2. Beta feedback** | Phase 5 (beta) | Beta users after ~2 weeks of use | In-app form + email | ⬜ create during Phase 4 |
| **3. Post-session mood** | In-product feature | App users after each session | In-app micro-form ("How do you feel? 1-10") | ⬜ planned feature (see FEATURES.md, RPE/mood) |

**Key rules:**
- Type 1 validates BEFORE we build (cheap to pivot now, expensive later).
- Type 2 improves what we built (bugs, friction, feature asks).
- Type 3 is a differentiator + wellness data — but only ship it if it never
  slows down the < 20 s log loop.
